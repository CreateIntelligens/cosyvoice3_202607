只影響「轉台文」那兩個模式。v5 是統計對齊出來的，乾淨但只涵蓋 naer 的語域（氣象、廣播、日常），文言幾乎命中不到。v1 是辭典法，覆蓋廣得多但噪音重（走找、條飛、烏白都是它的產物）。人工修正那層對每個版本都生效。
台文把華語詞換成台語漢字（颱風→風颱、東西→物件、把→共），輸出仍是漢字。v6 用 naer 290 小時訓練，而 naer 的原文就是台語漢字——這是模型的訓練分布本身，語調跟不轉換一樣自然。台羅換成羅馬拼音，詞更精準，但 v7 只學過 4.62 小時台羅，唸起來偏硬，而且漢字夾在台羅中間 1/10 會幻覺，所以是整句換或整句不換。查表用台華線頂＋教育部推薦用字＋naer 語料統計（23,484 詞）；加 Gemini 是補功能詞與句法（把→共、了→矣、他→伊），辭典結果會當提示餵給它，它改寫過頭就退回查表。送進模型的實際文字顯示在結果上。
Qwen 的詞彙表偏簡體，「廬」「傘」「佇」這類繁體字會退化成 UTF-8 位元組，模型從未把它們當成一個字。實測（official 模型合成華語）：不轉時「兇」「颱」「廬」都念錯；轉了就對。「乾杯」不轉會念成「前杯」，整句轉簡成「干杯」才正確——合併消除破音字的歧義，所以預設整句轉。
